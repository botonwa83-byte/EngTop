# EngTop 英语知识点补充计划

## 第一层：基础可用

- 小学语音、拼读、拼写、主题词汇和日常交际
- 初一词法、基本句型、疑问/否定/感叹句
- 每个知识点至少绑定 1 张讲解卡、3 道练习题和 1 张复习卡

## 第二层：初中主干

- 七大时态、被动语态、非谓语动词
- 宾语从句、定语从句、状语从句、条件句
- 比较级、最高级、情态动词、动词短语和构词法
- 听力场景、阅读题型、完形逻辑和应用文格式

## 第三层：中考综合

- 句型转换、汉译英、间接引语、反意疑问句
- 同义替换、语境猜词、主旨推断、段落衔接
- 记叙文、通知倡议、观点论证和综合表达

## 数据约束

- 知识点 ID 全局唯一
- 每个点必须包含年级、能力、讲解摘要和英文示例
- 题目通过 knowledgePointID 关联目录，禁止孤立题目
- 每季度按教材版本和考试大纲复核一次

## 开发顺序

1. 完成知识点图谱与筛选
2. 为基础层生成题目和讲解卡
3. 接入能力雷达与间隔复习
4. 扩充中考综合题型

## 当前批次进度

- 145 个知识点，覆盖小学、初一、初二、初三
- 每个知识点包含规则摘要、例句、掌握方法和易错提醒
- 每个知识点自动生成 3 道专项练习，共 435 道
- 练习结果接入六项能力、XP、连击和本地掌握状态
